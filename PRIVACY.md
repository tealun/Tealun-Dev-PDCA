# Privacy Policy

Last updated: 2026-11-05

Tealun Dev PDCA is a set of skill instructions for Claude. It contains no executable code, connects to no server, and adds no MCP servers, hooks or commands.

- **We collect nothing.** The plugin does not collect, store, transmit or sell any personal data, usage data or content.
- **Your conversations stay between you and Claude.** When the skills run, Claude reads their instructions inside your session. How Anthropic handles your conversations is governed by Anthropic's own privacy policy, not by this plugin.
- **Files the skills write stay in your project.** Some skills write documents into the project you are working on (for example `docs/explainer/` or `docs/98_evolution/evolution-ledger.md`). They are written only where you work and are never sent anywhere by the plugin.

Questions: open an issue at https://github.com/tealun/tealun-dev-pdca/issues.

# 隐私政策

最后更新：2026-11-05

Tealun Dev PDCA 是一组给 Claude 用的技能说明，不含可执行代码，不连接任何服务器，也不添加 MCP 服务器、hooks 或命令。

- **不收集任何数据。** 插件不收集、存储、传输或出售任何个人数据、使用数据或内容。
- **对话只在你和 Claude 之间。** 技能运行时，Claude 在你的会话里读取技能说明。Anthropic 如何处理你的对话，适用 Anthropic 自己的隐私政策，与本插件无关。
- **技能写出的文件留在你的项目里。** 部分技能会把文档写进你正在处理的项目（例如 `docs/explainer/`、`docs/98_evolution/evolution-ledger.md`），只写在你工作的地方，插件不会把它们发送到任何地方。

有问题请在 https://github.com/tealun/tealun-dev-pdca/issues 提 issue。
